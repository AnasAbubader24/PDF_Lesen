# Lokale Zertifikate

Hier `localhost+2.pem` und `localhost+2-key.pem` ablegen oder die Pfade in `.env` setzen.
Private Schlüssel und API-Schlüssel nicht committen. Diese Demo ist ausschließlich an localhost gebunden.
Der Browser muss der ausstellenden mkcert-CA vertrauen. Nur das Serverzertifikat zu installieren ersetzt dieses Vertrauen nicht.
